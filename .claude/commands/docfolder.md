Lee todos los archivos de la carpeta indicada en el argumento (o la carpeta actual si no se pasa ningún argumento) y genera un archivo README.md dentro de esa carpeta que documente su contenido.

El README debe seguir esta estructura:

1. **Título y propósito** — una línea que explique para qué existe esta carpeta dentro del proyecto RehabIA.

2. **Contenido** — tabla o lista con cada archivo, su tipo y una descripción de qué hace o qué contiene. Para archivos `.py` lee el código y describe las funciones principales. Para archivos `.ipynb` describe las secciones del notebook. Para archivos de datos (`.txt`, `.csv`) describe el formato y estructura.

3. **Cómo usar** — comandos concretos para ejecutar o abrir los archivos más importantes de la carpeta.

4. **Dependencias** — si aplica, qué otros archivos del proyecto necesita esta carpeta para funcionar (por ejemplo, si importa funciones de otro módulo).

Reglas:
- Escribe en español.
- Sé concreto y técnico: no pongas texto genérico que no aplique a los archivos reales.
- No inventes información: basate solo en lo que lees de los archivos.
- Si la carpeta ya tiene un README.md, actualízalo en vez de sobreescribirlo con contenido genérico.
- El archivo resultante debe guardarse como `README.md` dentro de la carpeta documentada.
